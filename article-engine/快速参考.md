# 快速参考手册

## 🚀 一分钟快速开始

```python
from article_system import ArticleSystem

# 1. 初始化
system = ArticleSystem("华为PC知识库(1)/华为PC全板块深度知识库_v7")

# 2. 生成软文
result = system.generate_with_validation(
    product_name="HUAWEI MateBook 14",
    scenario="学生学习",
    platform="公众号",
    target_audience="大学生"
)

# 3. 导出文件
files = system.export_result(result, "output")

# 4. 查看结果
print(f"得分: {result['validation_report'].final_score}/100")
print(f"标题: {result['article'].selected_title}")
```

## 📊 结果结构

### result 字典

```python
{
    "status": "success" | "failed",
    "article": ArticleContent,
    "validation_report": ValidationReport,
    "iterations": [...]
}
```

### ArticleContent 对象

```python
article = result['article']

# 标题
article.title_options        # List[TitleOption]
article.selected_title       # str

# 正文
article.opening             # str (开头)
article.body                # str (主体)
article.cta                 # str (CTA)
article.version_note        # str (版本提醒)

# 配图
article.images              # List[ImagePlan]

# 来源
article.knowledge_sources   # List[str]
article.facts_used          # List[str]

# 方法
article.to_markdown()       # 生成Markdown
article.to_dict()           # 转为字典
```

### ValidationReport 对象

```python
report = result['validation_report']

# 核心指标
report.final_score          # float (0-100)
report.can_publish          # bool

# 详细结果
report.fact_verification    # FactVerification
report.compliance_check     # ComplianceCheck

# 建议
report.summary              # List[str]
report.recommendations      # List[str]

# 方法
report.to_markdown()        # 生成报告
report.to_dict()            # 转为字典
```

## ⚙️ 高级用法

### 批量生成

```python
tasks = [
    ("HUAWEI MateBook 14", "学生学习", "公众号"),
    ("HUAWEI MateBook Pro", "内容创作", "小红书"),
]

for product, scenario, platform in tasks:
    result = system.generate_with_validation(
        product_name=product,
        scenario=scenario,
        platform=platform,
        target_audience="目标用户"
    )
    system.export_result(result, f"output_{product}")
```

### 自动重试

```python
result = system.generate_with_validation(
    product_name="HUAWEI MateBook 14",
    scenario="学生学习",
    platform="公众号",
    target_audience="大学生",
    auto_fix=True  # 自动重试，最多3次
)
```

### 自定义标题

```python
article = result['article']

# 查看所有标题
for i, opt in enumerate(article.title_options, 1):
    print(f"{i}. {opt.title}")

# 手动选择
article.selected_title = article.title_options[1].title

# 重新导出
system.export_result(result, "output")
```

## 🐛 常见问题

### Q: 找不到产品

```python
# 检查可用产品列表
from knowledge_retriever import KnowledgeRetriever
retriever = KnowledgeRetriever(kb_path)
products = retriever.get_available_products()
print(products)
```

### Q: 生成失败

```python
# 检查result状态
if result['status'] == 'failed':
    print(result.get('message'))
    if result.get('validation_report'):
        print(result['validation_report'].summary)
```

### Q: 得分太低

```python
# 查看验证报告
report = result['validation_report']
print("问题:", report.summary)
print("建议:", report.recommendations)

# 查看详细问题
print("事实核验:", report.fact_verification.warnings)
print("合规问题:", report.compliance_check.warnings)
```

### Q: 修改生成的内容

```python
# 生成后可以修改
article = result['article']

# 修改标题
article.selected_title = "你的新标题"

# 修改正文
article.body = "你的新正文"

# 重新导出
system.export_result(result, "modified_output")
```

## 💡 最佳实践

### 1. 选择合适的场景
- ✅ 学生 + 轻薄本 → 学生学习
- ✅ 职场 + 协同 → 移动办公

### 2. 平台风格要匹配
- 公众号：深度、完整
- 小红书：轻松、互动
- 朋友圈：简短、直接

### 3. 人群定位要精准
- ✅ 文科专业大学生
- ❌ 所有学生

### 4. 验证后再发布
```python
if report.can_publish and report.final_score >= 80:
    # 可以发布

else:
    # 需要人工审核
    review(article, report)
```
