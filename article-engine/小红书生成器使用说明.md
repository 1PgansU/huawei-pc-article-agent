# 小红书图文自动生成器 - 使用说明

## 📦 功能介绍

自动从知识库提取产品信息，匹配产品图片，生成小红书风格的图文展示页面。

## 🚀 快速使用

### 方式1：直接运行测试
```bash
python xhs_auto_generator.py
```

自动生成3个示例文件：
- `auto_xhs_matebook14_颜值.html` - 颜值种草风格
- `auto_xhs_matebook_pro_性能.html` - 性能实测风格  
- `auto_xhs_matebook14_学生.html` - 学生党风格

### 方式2：自定义生成

```python
from xhs_auto_generator import XHSAutoGenerator

# 初始化生成器
kb_path = "华为PC知识库(1)/华为PC全板块深度知识库_v7"
generator = XHSAutoGenerator(kb_path)

# 生成小红书图文
generator.generate(
    product_name="HUAWEI MateBook 14",  # 产品名称
    style="颜值种草",                    # 文案风格
    target_audience="学生党",            # 目标人群
    output_path="my_xhs.html"          # 输出路径（可选）
)
```

## 🎨 支持的风格

| 风格 | 适合场景 | 文案特点 |
|------|---------|---------|
| **颜值种草** | 新色发布、外观展示 | 强调配色、氛围感、少女心 |
| **性能实测** | 旗舰机型、高性能产品 | 强调处理器、跑分、专业性能 |
| **学生党** | 开学季、学生市场 | 强调学习场景、性价比、避雷 |
| **职场办公** | 商务场景、企业采购 | 强调便携、效率、多任务 |

## 📝 支持的产品

知识库中的所有产品都支持，包括：
- HUAWEI MateBook 14
- HUAWEI MateBook Pro
- HUAWEI MateBook Pro S
- HUAWEI MateBook Fold 非凡大师

## 🖼️ 图片匹配规则

生成器会自动查找最佳产品图片，优先级：
1. **商城款式图片** - 最优先，官方展示图
2. **images目录** - 产品宣传图
3. **配色外观关键词** - 优先选择配色、外观相关图片

## ✨ 生成的页面特点

✅ 左图右文的小红书经典布局  
✅ 真实产品图片（自动从知识库获取）  
✅ 情绪化口语化文案  
✅ Emoji段落标题  
✅ 话题标签 + 互动数据  
✅ 响应式设计（移动端适配）

## 🎯 使用示例

### 示例1：生成樱粉金颜值种草文案
```python
generator.generate(
    product_name="HUAWEI MateBook 14",
    style="颜值种草",
    target_audience="女性用户",
    output_path="matebook14_樱粉金.html"
)
```

### 示例2：生成Pro性能实测文案
```python
generator.generate(
    product_name="HUAWEI MateBook Pro",
    style="性能实测",
    target_audience="创作者",
    output_path="matebook_pro_性能.html"
)
```

### 示例3：批量生成多个型号
```python
products = [
    "HUAWEI MateBook 14",
    "HUAWEI MateBook Pro",
    "HUAWEI MateBook Pro S"
]

for product in products:
    generator.generate(
        product_name=product,
        style="颜值种草",
        target_audience="学生党"
    )
```

直接双击HTML文件用浏览器打开即可查看效果！

## 🔧 自定义扩展

### 添加新的文案风格

在 `xhs_auto_generator.py` 中添加新的生成方法：

```python
def _generate_your_style_content(self, product_name, facts, audience):
    return {
        "author": "你的作者名",
        "title": "你的标题",
        "sections": [
            {
                "emoji": "🎯",
                "title": "段落标题",
                "content": "段落内容"
            }
        ],
        "cta": "行动引导",
        "tags": ["#话题标签"]
    }
```

### 修改页面样式

编辑 `_build_html_template` 方法中的CSS样式即可。

## ⚠️ 注意事项

1. **图片路径**：确保知识库路径正确
2. **产品名称**：必须与知识库中的产品文件夹名称一致
3. **输出路径**：支持相对路径和绝对路径
4. **图片格式**：支持 jpg、jpeg、png、gif
