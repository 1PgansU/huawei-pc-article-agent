# 朋友圈文案生成 - 结构化提示词模板

> **硬性分叉（必须遵守，否则整篇作废）**
> - 你正在生成的是 **微信朋友圈销售短帖**，不是小红书、不是长软文、不是测评报告。
> - **禁止**出现：姐妹们/救命/美哭了/真香预警/闭眼入/少女心、长段落种草、#话题标签瀑布、左图右文小红书布局。
> - **必须**出现：短行多次换行（总字数约 100–200）、商务/促销 emoji（🔥✅✓）、✓参数 3–6 条、到店/私信/咨询行动引导。
> - 输出形态：**可直接复制到微信的纯文案** + 模拟朋友圈界面的 HTML（上文下图），不是「图文软文成稿」Markdown 报告。
> - 若输入里误带小红书情绪词，一律改写成销售短帖后再输出。

## 📋 使用方法

将以下提示词发送给GPT/Claude，替换占位符，生成朋友圈风格文案和HTML页面。

### 朋友圈文案规范（核心要求）

#### 1. 文案结构（严格遵守）

**第1行：标题（吸睛）**
```
{Emoji} {产品名称}｜{核心卖点/促销信息}
```

**第2-3行：核心卖点（简短有力）**
```
{产品亮点1} {Emoji}
{产品亮点2}
```

**第4-5行：促销信息/行动引导**
```
{促销信息/体验邀请} {Emoji}
```

**空一行**

**第6-8行：详细参数（分点列出）**
```
✓ {参数1}
✓ {参数2}
✓ {参数3}
```

#### 2. 文案特点

✅ **必须使用：**
- **简短有力**：每行不超过20字
- **多次换行**：保持段落分明
- **直接促销**：现货、抢购、限时、到店
- **商务emoji**：🔥✅✓✨📱💻🎯
- **行动引导**：欢迎咨询、到店体验、私信了解

❌ **禁止使用：**
- 长段落（朋友圈要简短）
- 过度情绪化（不是小红书）
- "姐妹们"、"救命"（太小红书风）
- 过于正式的官方话术

#### 3. 常用开头模板

**新品上市：**
- 🔥 {产品名}｜新品首发！

- 🎯 {产品名}｜展厅现货，随时体验

**咨询引导：**

### HTML页面布局要求

#### 1. 整体风格
- 模拟微信朋友圈界面
- 浅灰色背景 #f5f5f5
- 内容区白色背景

#### 2. 页面结构（从上到下）

**2.1 顶部栏**
```html
<div class="moments-header">
  <div class="back-btn">←</div>
  <div class="title">详情</div>
</div>
```

**2.2 发布者信息**
```html
<div class="author-section">
  <img class="avatar" src="avatar.jpg">
  <div class="author-name">{发布者姓名}</div>
</div>
```

**2.3 文案内容**
```html
<div class="text-content">
  {朋友圈文案，保留所有换行}
</div>
```

**2.4 图片区（网格布局）**
```html
<div class="images-grid">
  <img src="image1.jpg">
  <img src="image2.jpg">
  <img src="image3.jpg">
  <!-- 1-9张图片 -->
</div>
```
- 1张图：大图显示
- 2张图：左右排列
- 3张图：横向排列
- 4张图：2×2网格
- 6张图：2×3网格
- 9张图：3×3网格

**2.5 时间戳**
```html
<div class="timestamp">
  {发布时间}
</div>
```

**2.6 底部操作栏**
```html
<div class="action-bar">
  <div class="comment-input">发表评论：</div>
  <div class="emoji-btn">😊</div>
  <div class="image-btn">🖼</div>
  <button class="send-btn">发送</button>
</div>
```

### 文案长度规范

- **总字数：** 100-200字（不含emoji）
- **标题：** 10-15字
- **卖点：** 每行15-20字
- **参数：** 3-6条
- **结尾：** 10-15字

---

### Emoji使用规范

**高频emoji：**
- 🔥 火爆/热销
- ✅ 现货/到店
- ✨ 亮点/特色
- 📱 手机/数码
- 💻 电脑/笔记本
- 🎯 重点/核心
- ✓ 列举/参数
- 💥 爆款/促销
- ⚡ 性能/速度
- 🌸 配色/美观

**避免使用：**
- ❌ 过度可爱的emoji：🥺😭💗
- ❌ 小红书专属：救命、绝了
- ❌ 复杂的组合emoji

## 🎯 朋友圈 vs 小红书 对比

| 对比项 | 朋友圈 | 小红书 |
|--------|--------|--------|
| **文案长度** | 100-200字 | 500-800字 |
| **段落** | 多次换行，简短 | 长段落，详细 |
| **语气** | 商务、直接 | 种草、情绪化 |
| **Emoji** | 商务化 🔥✅✓ | 可爱化 😭💗🌟 |
| **促销** | 直接促销话术 | 种草引导 |
| **布局** | 上文下图 | 左图右文 |
| **适合** | 销售、门店 | 内容营销 |
